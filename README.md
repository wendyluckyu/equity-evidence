# 见微 · 个股证据诊断

一个以美的集团（000333.SZ）为研究对象的 AI Native Web 产品。用户提出问题，系统组织诊断维度、计算可复核指标，再由 DeepSeek 基于证据解释支持、反证、矛盾与未知。源代码不包含 API 密钥、用户画像、持仓或扶摇原始数据快照。

## 核心体验

1. 在首页的美的集团卡片点击“查看分析”，进入研究工作台。
2. 在“公司概览”查看盈利表现、经营现金流、关注事项及四类证据。报告期和资料覆盖范围始终可核对。
3. 向下找到“研究问答”，点击“盈利质量”“估值比较”“潜在风险”，或输入研究问题并点击“分析”。
4. 回答展示“AI 组织的证据解读”。点击“核对依据”或结论引用，展开“原始数据与计算口径”，查看字段、数值、单位、报告期、来源和公式。
5. 证据详情附有“验证路径”，列明需要补充的资料、核对方法和原文入口；可跳转财务、同行或行情。核查记录仅保留在本次页面会话。
6. 顶部栏目包括“公司概览”“财务数据”“同行比较”“行情与公告”“数据来源”。可切换财务期次及 20/60/120/240 个可用交易日行情区间。
7. 点击相关研究问题可继续提问。模型只接收最近三个问题，不包含完整历史回答或用户核查记录；它不是无限历史记忆聊天。

## 启动

需要 Node.js >= 22.13、npm，以及具备所需权限的扶摇和 DeepSeek API Key。

```sh
npm ci
cp .env.example .dev.vars
# 在本地编辑 .dev.vars，填入密钥；该文件被 Git 忽略
npm run dev -- --host 127.0.0.1
```

打开启动日志打印的本地地址。默认通常为 http://127.0.0.1:5173/。`npm run dev` 使用 Cloudflare 本地运行时；密钥从 `.dev.vars` 读取。也支持服务端 `process.env`，不要加 `NEXT_PUBLIC_` 或 `VITE_` 前缀。

| 环境变量 | 必需 | 作用 |
|---|---|---|
| HITHINK_FINANCE_API_KEY | 是 | 扶摇结构化金融数据 |
| DEEPSEEK_API_KEY | 是 | 服务端调用真实模型 |
| DEEPSEEK_MODEL | 否 | 默认 deepseek-flash；上线前已用账号可用模型列表验证 |

部署为 Cloudflare Workers 兼容产物；本项目使用 Sites 托管。生产密钥保存在托管平台的 secret 配置中，不进入代码或打包文件。`.openai/hosting.json` 仅记录站点标识。移植到新的 Sites 项目时更换为自己的站点标识。

```sh
node tests/run.mjs
npx tsc --noEmit
npm run build
```

## 产品选择

目标用户：希望先看懂公司近况、再逐步核对证据的个人投资者。首屏不要求用户先掌握财务术语。

选择单一公司做完整链路，避免以全市场覆盖牺牲可追溯性。美的的集团利润、现金流、扣非口径和海外相关风险可以形成多维研究问题。格力与海尔只作为有限比较样本，**不构成完整行业排名**。

产品输出的是研究线索与证据，不使用统一好坏评分，不输出直接买卖建议、目标价或确定性涨跌预测。

## 数据与计算

- 扶摇：三家公司的最近 12 个季度末合并利润表、资产负债表、现金流量表；当前估值；美的行情快照与最近一年日 K 线。展示最多 8 个可选择财务期次。
- 公告：美的 2026 半年度报告及摘要，最小必要事实摘录位于 `lib/filings.ts`；来源为深交所和巨潮资讯，附精确页码。公告资料披露截止 **2026-08-29**，核对日期 **2026-10-02**，不是实时事件流。
- 收入同比、归母同比、现金流同比：本年累计与上年同期间累计比较。基数小于等于零、缺失或非有限值时不计算普通同比。
- 毛利率：（营业收入－营业成本）÷营业收入。不得把营业总成本当营业成本。
- 现金流覆盖：经营现金流净额÷**合并净利润**，不混用归母净利润。
- 行情：前复权日收盘价；区间价格变化和收盘价最大回撤由程序计算，不等于总回报。
- 估值：使用上游 TTM 指标，未自行重算；不提供历史估值分位。历史财务选择不会把当前估值变成历史估值。
- 12 项请求分批、最高 3 个并发；同一 Worker 实例缓存 5 分钟。缓存不是跨实例全局缓存。

## AI 的角色和验证

真实调用 DeepSeek。模型读取用户问题、最近三个研究问题、公司类型、数据质量状态和当前证据库，选择重点维度、相关解读、反证及后续验证问题。它不自由生成展示事实。

证据库由指标计算、已核实公告摘录及明确边界组成。模型输出受限的证据选择 JSON，程序检查 ID、摘要与重点的对应、反证要求、字段白名单；再将所选解读与对应依据一并呈现。因此，不会接受“现金流引用支持市场份额第一”等自由新增断言，也不再因为复述已验证数字而失败。

这是受约束的证据解读，不是全功能研究 Agent：模型仍可能选出相关性不理想的条目；展示内容明确标为“AI 组织的证据解读”，原始条目可逐一核对。模型最多纠正一次，失败会明确报错，不会伪装成 AI 成功。

三项最新中报指标与已整理公告交叉核对，数字冲突暂停综合解读。正面、负面、矛盾和未知证据同时可见；摘要也有直接引用。每条证据附字段、原文、范围、验证路径和跳转入口。用户核查记录仅留在当前页面会话，不自动升级为事实，不发送给模型。

完整记录见 [AI 使用与验证](docs/AI_USAGE_AND_VALIDATION.md)、[测试说明](docs/TESTING.md)、[数据字典](docs/DATA_DICTIONARY.md)。

## 故障与边界

缺失、无权限、业务错误、网络失败、超时及限流均单独保留状态，不补零；核心财务不可用则停止 AI 解读。时点未知和数据陈旧有提示。

不支持全市场搜索、实时新闻聚合、订单跟踪、账龄或存货明细、交易执行、个人持仓、定时自动刷新、历史时点回测和历史估值分位。历史财务记录可能为上游最新重述版本，并非当年首次披露时点快照。仅最新中报三项指标完成公告交叉验证；同行与其他期次未逐条复核公告。

AI 请求有单实例每 IP 每分钟 6 次的限制；这不是全局持久化额度管理。公开访问前应确认数据再展示权限及模型调用预算，正式产品需额外全局限流与访问控制。

## 代码结构

- `app/api/data/route.ts`：服务端读取数据，不向客户端暴露密钥。
- `lib/market.ts`：授权数据接入、并发、缓存与异常状态。
- `lib/finance.mjs`：纯函数指标、报告期对齐、路径规则。
- `lib/diagnosis.ts`：证据对象、来源与确定性结论。
- `lib/ai-guard.mjs`：模型输出验证。
- `components/workbench.tsx`：研究主流程、证据抽屉、结构化浏览器工具。
- `components/data-panels.tsx`：财务图、同行表、行情图和来源面板。
- `tests/`：合成数据的计算、故障及合规边界测试。

WebMCP 在支持的浏览器中提供 `read_diagnosis_evidence`（读取）与 `run_equity_diagnosis`（运行并更新页面）；不支持时不影响网页使用。

## 时效与研究范围

行情使用最后一个有效交易记录日期、估值使用上游快照时点，采用 10 个自然日阈值；最新财务采用报告期末 200 日阈值。阈值是保守的产品规则，不是交易日历判断，也不保证已覆盖最新披露。过期/未知数据被标为待验证；针对过期估值或行情的问题在模型调用前停止。用户明确选择历史报告期时只作历史财务研究。

公告仅覆盖列明的半年报与摘要，不声称实时事件全集。验证路径引导用户核对附注和此后公告；本版不自动检索或验证用户新增资料。
